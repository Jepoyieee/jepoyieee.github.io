## Publish using GitHub Pages (beginner steps)

### Step 1 — Download and extract

Download `jepoyieee_portfolio.zip` and extract it on your computer. Open the extracted `jepoyieee_portfolio` folder. You should see `index.html` and `README.md`.

### Step 2 — Create the repository

1. Sign in at https://github.com using the account `jepoyieee`.
2. Click the **+** button near the top-right, then choose **New repository**.
3. Enter this exact repository name: `jepoyieee.github.io`
4. Select **Public**.
5. Click **Create repository**. You can leave the other options unchanged.

### Step 3 — Upload the website files

1. In the new repository, choose **Add file → Upload files**.
2. Open the extracted portfolio folder on your computer.
3. Upload `index.html` and `README.md` (upload the files themselves, not a ZIP containing them).
4. Scroll down and click **Commit changes**.
5. Check that `index.html` appears on the repository's main page, not inside another subfolder.

### Step 4 — Turn on GitHub Pages

1. Open the repository's **Settings** tab.
2. In the left sidebar, choose **Pages** (usually under **Code and automation**).
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Set **Branch** to `main` and the folder to `/(root)`.
5. Click **Save**.

### Step 5 — Visit your portfolio

After GitHub finishes publishing, open: **https://jepoyieee.github.io/**

It can take a few minutes for the first publish. If the site does not appear immediately, refresh later and check **Settings → Pages** for the deployment status.

### Updating the website later

When you edit `index.html`, upload the updated file to the same repository and commit the changes. GitHub Pages will publish the update automatically after a short delay.
