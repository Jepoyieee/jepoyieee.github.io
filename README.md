# Jepoyieee Portfolio — GitHub Pages guide

Files: `index.html`, `styles.css`, `script.js`, `favicon.svg`, `assets/` (keep this structure).

## Publish
1. On GitHub, click **New repository**. Name it exactly **jepoyieee.github.io**, set it to **Public**, then **Create repository**.
2. Click **uploading an existing file**. Unzip this package and drag the *contents* (index.html, styles.css, script.js, favicon.svg and the assets folder) into the page. `index.html` must be in the repository root.
3. Click **Commit changes**.
4. Go to **Settings → Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch **main**, folder **/ (root)**, then **Save**.
5. After 1–2 minutes your site is live at https://jepoyieee.github.io

## Edit
Search `index.html` for the `EDIT:` comments (intro, biography). To change tile names, project titles, descriptions and status text directly. Replace `assets/p1–p4.svg` and `assets/about.svg` with your own images (keep the same file names or update the `src`). Add a project's real GitHub link by wrapping its title in an `<a>`.
Project cards are labelled as concepts/academic projects until you add confirmed details.
